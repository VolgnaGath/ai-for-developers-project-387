# Call Calendar

Приложение бронирования звонков: один владелец публикует типы событий, гости бронируют свободные слоты без аккаунта и без входа. Доменные термины — на русском; код и API — на английском.

## Language

**Владелец**:
Единственный заранее заданный профиль, который управляет календарём: создаёт типы событий и видит брони. Отдельного профиля Host нет.
_Avoid_: админ, Host, host

**Гость**:
Человек, который бронирует слот без аккаунта и без входа.
_Avoid_: пользователь

**Тип события**:
То, что владелец публикует для бронирования: название, описание, длительность 15 или 30 минут.
_Avoid_: вид брони, тип встречи

**Слот**:
Свободный интервал времени `[start, end)`, который вычисляет сервер.
_Avoid_: интервал, таймслот

**Бронь**:
Подтверждённое бронирование гостя на конкретный слот.
_Avoid_: встреча (допустима только в UI-подписи «Предстоящие встречи»), booking, резервирование

**Таймзона конфига**:
Таймзона из `PublicConfig.timezone`; в ней живёт весь календарь: сетка, «сегодня», границы дней, параметры `from`/`to`. Таймзона браузера гостя в v1 не участвует.
_Avoid_: локальная таймзона, таймзона гостя

**Календарная дата**:
Дата без времени, трактуемая в таймзоне конфига (типы `plainDate`/`utcDateTime` из контракта).

**Окно бронирования**:
Горизонт в 14 дней от «сейчас», внутри которого существуют слоты; за окном сервер слоты не отдаёт.

**Рабочие часы**:
Дни и часы, в которые генерируются слоты. По умолчанию: Пн-Пт 09:00-18:00 (`PublicConfig.workingHours`). Слоты за пределами рабочих часов не существуют.

**Шаг сетки**:
Минимальный интервал между слотами. По умолчанию 15 минут (`PublicConfig.slotStepMinutes`): слоты начинаются на 09:00, 09:15, 09:30 и т.д.

**Статус брони**:
В v1 единственный статус — `confirmed`. Бронь не может быть отменена или изменена через API.

**Поток бронирования**:
Последовательность действий гостя: выбор типа события → выбор даты в календаре → выбор свободного слота → заполнение формы (имя, опционально email) → подтверждение. Без аккаунта и без входа.

**Возможности Владельца**:
Просмотр списка типов событий и броней (с фильтрами по дате), создание/редактирование/удаление типов событий. Админка (`/admin/*`) доступна без аутентификации — осознанное решение для MVP.

## Доменные правила

**Кросс-типовая блокировка слотов**:
Любая бронь блокирует совпадающие слоты для ВСЕХ типов событий. Если гость забронировал 10:00–10:30 по типу «Консультация», слот 10:00–10:15 по типу «Онбординг» тоже недоступен.

**Ограничения типа события при наличии броней**:
- Длительность типа события заблокирована (нельзя менять) если на него есть хотя бы одна бронь.
- Тип события нельзя удалить если на него есть хотя бы одна бронь.
- В обоих случаях сервер возвращает 409.

**Семантика ошибок**:
- `409 slot_unavailable` — слот уже занят другой бронью.
- `422 invalid_slot` — слот невалиден (вне рабочих часов, в прошлом, за пределами окна).
- `409 event_type_has_bookings` — нельзя удалить тип с бронями.
- `409 event_type_duration_locked` — нельзя менять длительность типа с бронями.
- `400 bad_request` — некорректный запрос (валидация полей).
- `413 payload_too_large` — тело запроса слишком велико.
